Sobre o Projeto

O Mind Studio Games nasceu como um projeto acadêmico da disciplina de Projeto de Extensão do curso de Ciência da Computação. Nosso objetivo foi criar um conjunto de "benchmarks" mentais, inspirada em clássicos como o Human Benchmark, para testar e desafiar nossas habilidades.

Construído com Python, Flask e SQLite no backend, e HTML, CSS e JavaScript puro no frontend, este site é o resultado do nosso esforço em aprender e aplicar conceitos de desenvolvimento web.

Desenvolvido por: Pierre, Renan, Johann, Kewy e Rodolfo.
